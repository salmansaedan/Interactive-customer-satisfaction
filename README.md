## الهيكل التنظيمي المُطبق

### التسلسل الإداري
```
المدير الأول: سلمان سعدان
├── أحمد محمد (مدير مستوى ثاني) - 7 موظفين
├── فاطمة علي (مدير مستوى ثاني) - 7 موظفين  
├── محمد خالد (مدير مستوى ثاني) - 7 موظفين
├── نورا عبدالله (مدير مستوى ثاني) - 7 موظفين
├── يوسف إبراهيم (مدير مستوى ثاني) - 7 موظفين
├── مريم حسن (مدير مستوى ثاني) - 7 موظفين
└── عبدالرحمن سالم (مدير مستوى ثاني) - 7 موظفين

إجمالي: 1 مدير أول + 7 مديرين مستوى ثاني + 49 موظف
السعة القصوى: 24,500 عميل (49 موظف × 500 عميل/موظف)
```

### حدود السعة المُطبقة
- **500 عميل لكل موظف** - يُرسل تنبيه عند 80% (400 عميل)
- **7 موظفين لكل مدير مستوى ثاني** - يُرسل تنبيه عند الوصول للحد الأقصى
- **7 مديرين مستوى ثاني لكل مدير أول** - يُرسل تنبيه عند الوصول للحد الأقصى

## الميزات الجديدة للهيكل التنظيمي

### 1. مراقبة السعة التلقائية
- **فحص السعة الفوري**: `/api/capacity/check`
- **إحصائيات مفصلة**: `/api/capacity/stats`
- **تنبيهات ذكية**: إنشاء تنبيهات عند اقتراب الحد الأقصى

### 2. نظام التنبيهات المتقدم
- **تنبيه السعة الممتلئة**: عند وصول الموظف لـ80% من السعة
- **تنبيه الحاجة لموظف جديد**: عند امتلاء فريق المدير
- **تنبيه الحاجة لمدير جديد**: عند امتلاء هيكل المدير الأول

### 3. التوزيع الذكي للعملاء
- **توزيع تلقائي**: `/api/capacity/distribute`
- **توزيع متوازن**: على الموظفين المتاحين
- **تتبع العبء**: لكل موظف ومدير

### 4. تقارير شاملة
- **خريطة الهيكل التنظيمي**: عرض بصري للتسلسل الإداري
- **إحصائيات مفصلة**: لكل مستوى إداري
- **معدل الإشغال**: للموظفين والمديرين
- **العملاء غير المربوطين**: والحاجة لتوزيعهم

## البنية التقنية

### قاعدة البيانات
- **Cloudflare D1 SQLite**: قاعدة بيانات موزعة عالمياً
- **الجداول الجديدة**:
  - `level1_managers`: مديرين المستوى الأول
  - `level2_managers`: مديرين المستوى الثاني
  - `employees`: الموظفين
  - `capacity_alerts`: تنبيهات السعة
- **الروابط**: العملاء مربوطين بالموظفين عبر `employee_id`

### خدمات السعة
- **CapacityService**: خدمة شاملة لمراقبة وإدارة السعة
- **فحص تلقائي**: للحدود والتنبيهات
- **توزيع ذكي**: للعملاء الجدد
- **تقارير تفصيلية**: لكل مستوى تنظيمي

### واجهة المستخدم
- **تبويب الهيكل التنظيمي**: واجهة شاملة للإدارة
- **لوحة المعلومات**: إحصائيات فورية
- **التنبيهات النشطة**: عرض وحل التنبيهات
- **التبويبات الفرعية**: نظرة عامة، موظفين، مديرين، تقارير

## استخدام النظام

### 1. مراقبة السعة
```javascript
// فحص السعة وإنشاء تنبيهات
POST /api/capacity/check

// الحصول على الإحصائيات
GET /api/capacity/stats

// عرض التنبيهات النشطة  
GET /api/capacity/alerts
```

### 2. إدارة الموظفين
```javascript
// إضافة موظف جديد
POST /api/employees
{
  "name": "اسم الموظف",
  "email": "email@company.com",
  "phone": "05xxxxxxxx", 
  "level2_manager_id": 1
}

// عرض قائمة الموظفين
GET /api/employees
```

### 3. إدارة المديرين
```javascript
// إضافة مدير مستوى ثاني
POST /api/level2-managers
{
  "name": "اسم المدير",
  "email": "email@company.com",
  "phone": "05xxxxxxxx",
  "level1_manager_id": 1  
}

// عرض قائمة المديرين
GET /api/level2-managers
```

### 4. التوزيع والتقارير
```javascript
// توزيع العملاء غير المربوطين
POST /api/capacity/distribute

// تقرير الهيكل التنظيمي الشامل
GET /api/organization/report
```

## النشر والتكوين

### منصة النشر
- **Cloudflare Pages**: نشر عالمي على الـ edge
- **وضع التطوير**: محلي باستخدام wrangler
- **قاعدة البيانات**: D1 SQLite مع الـ --local للتطوير

### متغيرات البيئة
- `RESEND_API_KEY`: لخدمة البريد الإلكتروني
- `FROM_EMAIL`: البريد المرسل منه
- `APP_URL`: رابط التطبيق
- `COMPANY_NAME`: اسم الشركة
